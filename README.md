# Digital Menu App 🍽️

A mobile application for restaurants to showcase their menu items digitally. Built with [Expo](https://expo.dev) and React Native.

> **Note:** This app was entirely built with AI agents.

## Features

- Browse menu items by category
- View detailed information about each dish
- Place orders directly from the app

## Getting Started

1. Install dependencies

   ```bash
   npm install
   ```

   **Note:** This project uses the latest stable version of Expo and works best with Node.js v20. If you have fnm installed, you can switch to the recommended version:

   ```bash
   fnm use 20
   ```

2. Start the app

   ```bash
   npm start
   ```

In the output, you'll find options to open the app in a:

- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go) on your physical device

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **app-example** directory and create a blank **app** directory where you can start developing.
